# Maira · Portfolio

My freelance web and app development portfolio, built with plain HTML, CSS and a little JavaScript. There's no build step and nothing to install.

**Live site:** https://manimac-pie.github.io/portfolio/

## Files

- `index.html`: all the page content
- `styles.css`: the design (colours, fonts, layout)
- `script.js`: mobile menu and footer year
- `images/`: project screenshots

## Preview locally

```sh
open index.html
```

## Updating the live site

GitHub Pages republishes automatically whenever you push to `main`:

```sh
git add -A
git commit -m "Describe your change"
git push
```

Changes go live within a minute or two.
